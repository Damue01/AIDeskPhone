# ESP32-S3 参考物料清单

本清单对应当前 HG113 + ESP32-S3 DevKitC-1 + GPIO4/2/1 基线。它用于制作参考样机，不代表成品认证或任意同名模块都可直接替换。购买和焊接前必须核对模块原理图、供电范围、引脚定义和实际电话机内部结构。

## 必需物料

| 数量 | 物料 | 推荐规格 | 验证状态与注意事项 |
| ---: | --- | --- | --- |
| 1 | HG113 桌面电话与听筒 | 外线完全断开的样机 | 已作为机械结构和听筒基线；不同批次线序必须实测 |
| 1 | ESP32-S3 开发板 | ESP32-S3 DevKitC-1，USB 数据接口 | 当前主固件构建基线；由 USB 供电，GPIO 为 3.3 V 逻辑 |
| 1 | USB 数据线 | 支持数据传输，匹配开发板接口 | 仅充电线无法烧录或查看串口 |
| 1 | 蜂鸣器或带驱动输入的蜂鸣器模块 | 能响应约 3 kHz PWM | GPIO2 只接信号/低电流负载；大电流、电磁式或不明模块需加驱动级 |
| 1 | LED | 普通低电流指示 LED | GPIO1 输出；确认极性 |
| 1 | LED 限流电阻 | 建议从 330 Ω 起，根据 LED 压降和目标电流复核 | 不得省略或短接 |
| 若干 | 绝缘导线、焊锡、热缩管和固定材料 | 适合低压弱电连接 | 装机前做短路、极性和拉力检查 |

## 音频链路物料

| 数量 | 物料 | 推荐规格 | 验证状态与注意事项 |
| ---: | --- | --- | --- |
| 1 | CSR8645 蓝牙音频模块或等效模块 | Windows 可同时识别输入与输出，模块明确支持听筒麦克风和喇叭连接 | CSR8645 是当前参考方案；不同载板引脚和增益可能不同 |
| 1 | 独立 3.7 V 音频模块电源方案 | 符合所购模块说明，带必要保护 | 不要把 5 V 直接接到 `BAT+`，也不要由 ESP32 3.3 V 引脚供电 |
| 1 | RJ9/R9/4P4C 转接线或分线板 | 便于无损分离听筒四芯线 | 线色和插头顺序不可靠，必须用万用表及录放音测试确认 |

如果不需要真实听筒音频，可省略本节物料并使用电脑现有麦克风和扬声器。

## 工具

- 带通断和直流电压档的万用表；
- 可控温电烙铁及基本焊接工具；
- 绝缘胶带或热缩管；
- 用于 ESP32 烧录和串口监视的 Windows 10/11 电脑。

## 替代件规则

1. 替换 ESP32 板卡时，先确认 PlatformIO board ID、USB/串口方式和 GPIO4/2/1 是否可安全使用；未验证板卡不能沿用“当前支持”标签。
2. 替换蜂鸣器时，先测输入电流。超过 GPIO 安全驱动范围或含感性负载时使用晶体管/MOSFET 驱动及必要保护。
3. 替换蓝牙音频模块时，必须分别验证 Windows 录音、播放、摘挂机噪声和听筒音量，不能只验证蓝牙已连接。
4. 不维护价格和购买链接；价格、卖家和模块修订变化快，采购时以电气规格和实测结果为准。

接线、供电警告和验证步骤见[标准参考手册](../REFERENCE_MANUAL.md)，现场证据见[硬件资料索引](README.md)。
