## 使用限制

- 当前主控是 ESP32-S3；照片中的 ESP32-C3 只代表历史样机。
- 照片只能证明可见元件、丝印和机械位置，不能替代万用表测量。
- 线色、焊盘功能、电源极性和开关状态必须以现场实测为准。
- 电话外线必须保持断开。
