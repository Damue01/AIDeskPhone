# AiLandLine 电话机硬件后续计划

## 当前目标

把老式座机改成一个可由电脑触发的交互电话：

1. 电脑发送信号。
2. ESP32-C3 Super Mini 收到信号。
3. DFPlayer Mini 播放铃声。
4. 座机内置喇叭响铃。
5. 抬起听筒后，ESP32-C3 检测到摘机状态。
6. 停止响铃，进入已接听状态。

## 已确定硬件

- ESP32-C3 Super Mini
- 座机内置喇叭，约 8Ω 0.25W
- DFPlayer Mini / MP3-TF-16P 语音播放模块
- MCP23017 I2C 16 位 IO 扩展模块
- 独立 5V 电源
- 万用表、烙铁、导线、电阻
- 蓝牙耳机模块，可选保留

## 音频方案

优先使用 DFPlayer Mini，不再直接用蓝牙耳机板推座机喇叭。

DFPlayer 接线：

```text
5V                 -> DFPlayer VCC
GND                -> DFPlayer GND
ESP32-C3 GPIO21/TX -> 1kΩ -> DFPlayer RX
ESP32-C3 GPIO20/RX <- DFPlayer TX，可选

座机喇叭一端       -> DFPlayer SPK-1
座机喇叭另一端     -> DFPlayer SPK-2
```

注意：

- 喇叭不要接 GND。
- `SPK-1 / SPK-2` 是一对功放输出。
- 首次测试音量设小，例如 `5/30`。
- TF 卡内先放 `/mp3/0001.mp3` 或根目录 `0001.mp3` 作为铃声。

## 座机按键板 X7 引脚

X7 从左到右：

```text
1  SPK-
2  SPK+
3  INUSE
4  NC
5  GND
6  R4
7  R3
8  R2
9  R1
10 C1
11 C2
12 C3
13 C4
14 C5
15 C6
```

按键矩阵只需要接：

```text
R1 R2 R3 R4
C1 C2 C3 C4 C5 C6
```

也就是 X7 第 6 到第 15 脚。

建议：

- 不接 X7 的 `SPK+ / SPK-`，喇叭直接接 DFPlayer。
- `INUSE / NC / GND` 暂时不接。
- 按键矩阵接 MCP23017，不直接占用 ESP32-C3 的 10 个 GPIO。

## MCP23017 方案

ESP32-C3 与 MCP23017：

```text
ESP32-C3 3V3       -> MCP23017 VCC
ESP32-C3 GND       -> MCP23017 GND
ESP32-C3 GPIO8/SDA -> MCP23017 SDA
ESP32-C3 GPIO9/SCL -> MCP23017 SCL
```

MCP23017 的 10 个 IO 接 X7：

```text
R1 R2 R3 R4
C1 C2 C3 C4 C5 C6
```

后续代码用矩阵扫描识别数字键、功能键。

## 摘机检测

必须找到座机的叉簧开关，也就是听筒压下/抬起会变化的触点。

用万用表蜂鸣档找：

```text
听筒放下：导通或断开
听筒抬起：状态相反
```

接线建议：

```text
叉簧开关一端 -> ESP32-C3 某个 GPIO，例如 GPIO10
叉簧开关另一端 -> GND
代码中使用 INPUT_PULLUP
```

如果找不到原叉簧开关，可以替代：

- 微动开关
- 限位开关
- 干簧管 + 小磁铁

## 电脑触发方案

优先用 Wi-Fi HTTP：

```text
GET http://电话机IP/ring
```

ESP32-C3 收到 `/ring` 后：

1. 设置状态为 ringing。
2. 通过串口命令让 DFPlayer 播放 `0001.mp3`。
3. 循环播放或定时重播。
4. 检测到摘机后停止播放。

也可以用 USB 串口触发：

```text
电脑发送 RING\n
ESP32-C3 收到后响铃
```

## 可选蓝牙模块

蓝牙耳机板不建议直接推座机 8Ω 喇叭。

原因：

- 蓝牙耳机板通常用于 16Ω/32Ω 小耳机。
- 座机喇叭是 8Ω，负载过重。
- 直接接可能触发保护静音。

如果保留蓝牙耳机板：

```text
5V -> 降压模块 -> 4.0V -> 蓝牙板 BAT+ / BAT-
```

或者继续用蓝牙板自己的 USB 口供 5V。

不要：

- `L-` 接 GND
- `L+ / L-` 接同一个点
- 蓝牙输出接座机主板 `SPK+ / SPK-`
- 蓝牙耳机小喇叭和座机大喇叭并联

## 可能还需要的物料

如果手上没有，再补：

- 5V 2A 电源
- 1kΩ、10kΩ 电阻
- 细硅胶线，建议 30AWG
- 热缩管
- 助焊剂
- 排针、杜邦线
- TF 卡
- 微动开关或干簧管，用于摘机检测备用
- Mini360 / MP1584 降压模块，用于蓝牙板 4.0V 供电

## 下一步实施顺序

1. 用 DFPlayer + 座机喇叭单独测试播放 `0001.mp3`。
2. ESP32-C3 串口控制 DFPlayer 播放、停止、调音量。
3. 找到叉簧开关，做摘机检测。
4. 实现电脑发 `/ring` 后响铃，摘机后停止。
5. 接 MCP23017，扫描 X7 第 6 到第 15 脚的按键矩阵。
6. 根据按键实现拨号、挂断、重播等功能。
7. 再决定是否保留蓝牙耳机板做通话音频。
