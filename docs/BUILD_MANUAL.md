# AI Desk Phone 制作与维护手册

- 整理日期：2026-06-28
- 固件版本：`hybrid-ble-config-v1`
- BLE HID 名称：`AIDeskPhoneKB`
- 默认控制台地址：`http://127.0.0.1:8765`

这份手册按实际制作顺序组织，目标是让读者能从材料准备开始，完成控制链路、音频链路和最终装机。开发过程中的临时脚本、测试记录和个人快捷键方案不放入本文档。

## 1. 系统结构

控制链路：

```text
座机摘挂机/按压机构
  -> ESP32-C3 GPIO1 / ADC
  -> ESP32-C3 固件判断按下/释放
  -> BLE HID 键盘 AIDeskPhoneKB
  -> Windows 目标软件快捷键
```

音频链路：

```text
座机听筒麦克风和喇叭
  -> RJ9/R9/4P4C 四芯听筒线
  -> CSR8645 蓝牙音频模块 MIC / SPK 焊盘
  -> Windows 蓝牙耳机输入/输出
```

两条链路独立调试。ESP32-C3 不处理音频，CSR8645 不参与快捷键控制。

## 2. 材料清单

| 材料 | 作用 | 备注 |
| --- | --- | --- |
| 老式桌面座机 | 提供外壳、听筒和摘挂机结构 | 本项目使用富桥 HCD28(3)P/TSD 作为样机 |
| ESP32-C3 SuperMini | 读取摘挂机/按压状态，发送 BLE HID 快捷键 | 固件使用 GPIO1 / A1 作为输入 |
| CSR8645 蓝牙音频模块 | 连接听筒麦克风和喇叭 | 需要 3.7V 供电 |
| RJ9/R9/4P4C 听筒线或转接板 | 分出听筒的麦克风线和喇叭线 | 四芯线，最终线序以实测为准 |
| 3.7V 电源 | 给 CSR8645 供电 | 不使用 ESP32-C3 的 3.3V，不把 5V 接到 `BAT+` |
| 万用表 | 测电压、通断和线序 | 接线前后都需要 |
| 杜邦线、夹线、热缩管、绝缘胶带 | 临时连接、最终固定和绝缘 | 装机前确认没有裸露线头 |
| Windows 电脑 | 烧录固件、打开控制台、配对蓝牙设备 | 目标软件快捷键由用户自己的软件决定 |

照片资料见 [照片索引](electronics/photo-index.md)。

## 3. 安全边界

1. 电话外线不接入。本项目只使用座机外壳、听筒和低压内部结构。
2. CSR8645 使用 3.7V 供电。
3. ESP32-C3 的 3.3V 不给 CSR8645 供电。
4. 5V 不接 CSR8645 的 `BAT+`。
5. 未确认功能的听筒线只允许接到低压音频脚，不接任何电源脚。
6. 最终装机前，所有焊点、线头和模块背面都要做绝缘和应力释放。

## 4. 软件环境

如果固件已经刷入 ESP32-C3，直接运行启动脚本：

```powershell
.\Start_AI_Desk_Phone.bat
```

需要指定串口时：

```powershell
.\Start_AI_Desk_Phone.bat COM5
```

启动脚本会检查 Python 虚拟环境、安装依赖，并打开网页控制台。控制台会持续扫描 ESP32-C3 串口；USB 断开后重新插入，也会继续尝试连接。

首次烧录固件时，先安装 Python 依赖：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

编译固件：

```powershell
.\.venv\Scripts\platformio.exe run -d firmware\esp32c3_ble_gpio
```

烧录固件：

```powershell
.\.venv\Scripts\platformio.exe run -d firmware\esp32c3_ble_gpio -t upload
```

PlatformIO 会自动选择可用串口。电脑上有多个串口，或需要指定实际端口时：

```powershell
.\.venv\Scripts\platformio.exe run -d firmware\esp32c3_ble_gpio -t upload --upload-port COM5
```

如果控制台一直显示正在扫描，并且 Windows 只看到 `COM1`，说明 ESP32-C3 还没有枚举成 USB 串口。`COM1` 通常是 Windows 系统内置通信端口，不是本项目的板子。此时先换 USB 口或 USB 数据线，重新插拔几次，并检查板子供电和 BOOT/复位状态。Windows 正常识别后，控制台会自动连接新的 `COMx`。

## 5. 控制链路制作

1. 保持电话外线断开。
2. 将 ESP32-C3 通过 USB-C 连接 Windows 电脑。
3. 烧录 `firmware/esp32c3_ble_gpio` 固件。
4. 将摘挂机/按压检测点接入 ESP32-C3 的 GPIO1 / A1。
5. 启动本地控制台：

```powershell
.\Start_AI_Desk_Phone.bat
```

6. 打开 `http://127.0.0.1:8765`。
7. 操作电话摘挂机/按压机构，观察 ADC 曲线和状态变化。
8. 调整按下阈值、释放阈值、消抖时间和锁定时间，让真实动作能稳定触发。
9. 保存配置，确认日志中出现 `ESP32 已确认配置写入板子。`

保存配置时只保留一个控制台网页窗口。打开多个 `http://127.0.0.1:8765` 页面可能占用浏览器连接，导致保存请求超时。出现超时后，关闭其他控制台窗口，保留一个页面并强制刷新后再保存。

本项目不保留额外的串口、状态或扫描脚本。控制台就是唯一调试入口。

## 6. 快捷键配置原则

快捷键由用户自己的 Windows 软件决定。制作时先确认目标软件的快捷键，再填入控制台。

示例场景：

- 语音输入软件：按下电话动作触发开始/停止语音输入。
- 通话软件：摘机接听，挂机挂断。
- 会议软件：按压静音或取消静音。

配置原则：

1. 在目标软件中确认快捷键。
2. 在控制台中分别配置按下动作和释放动作。
3. 使用“模拟按下/模拟释放”确认 Windows 能收到快捷键。
4. 再用真实电话动作验证。
5. 如果目标软件更换，重新配置快捷键即可，不需要改固件。

## 7. Windows 蓝牙配对

1. 打开 Windows 蓝牙设置。
2. 搜索并配对 `AIDeskPhoneKB`。
3. 配对完成后，在控制台中执行模拟动作。
4. 确认目标软件响应后，再进行真实电话动作测试。

## 8. 音频链路制作

CSR8645 负责蓝牙音频，不参与 ESP32-C3 的快捷键控制。

供电：

```text
CSR8645 BAT+ / BAT- = 3.7V
```

接线：

1. 给 CSR8645 接 3.7V 电源。
2. 长按中间按键约 4-5 秒，使模块进入红蓝闪烁配对状态。
3. 在 Windows 中把 CSR8645 配对为蓝牙耳机/免提设备。
4. 将 RJ9/R9/4P4C 听筒四芯线分成两对。
5. 喇叭候选线接 CSR8645 `L+ / L-` 或 `R+ / R-`。
6. 麦克风候选线接 CSR8645 `MIC+ / MIC-`。
7. 录音和播放都正常后，再固定焊接。

线序不能只凭颜色判断。常见颜色可以作为尝试顺序，但最终以转接板标注、万用表通断和录音/播放检查为准。

## 9. 装机检查

装回座机外壳前确认：

1. ESP32-C3 固定牢靠，USB 口可访问。
2. CSR8645 和 3.7V 电源固定牢靠。
3. 电话外线未接入。
4. 所有电源线、音频线和信号线无短路。
5. 所有裸露焊点已绝缘。
6. 听筒线活动时不会拉扯焊点。
7. 摘挂机/按压机构动作不会压到模块或线束。
8. Windows 能连接 `AIDeskPhoneKB`。
9. 目标软件能按配置响应电话动作。
10. CSR8645 音频输入和输出正常。
11. 座机本体显示正常；如果显示异常或不亮，先更换座机电池。
