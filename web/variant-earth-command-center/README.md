# 服务通信中枢页面

这是一个独立静态页面，用来探索 AI 桌面电话的服务通信中心视觉方向。页面可以直接通过静态服务器运行，不依赖现有 Python 控制台。

```powershell
python -m http.server 8790 --bind 127.0.0.1 --directory web\variant-earth-command-center
```

打开：

```text
http://127.0.0.1:8790/
```

## 页面定位

当前方向是“服务通信中枢”，不是军事化指挥台。地球负责表达通信覆盖、链路态势和实时字符层；两侧面板负责显示服务状态和视图控制。

## 状态模型

- 系统状态：在线、暂停，用来表达整个通信中枢是否在运行。
- AI 服务响应率：模拟 AI 接线员服务的可用性与响应稳定性。
- 话机链路：正常、排队、转接、同步，用来表达 HG113 与本机服务之间的工作状态。
- 当前服务区：模拟当前通信节点或服务区。
- 事件流：展示链路握手、任务队列、蜂鸣器、指示灯等运行事件。

## 视觉原则

- 常态使用青绿色和暖白，表达服务在线、链路稳定。
- 红色只作为告警色，不再作为页面主色。
- UI 面板贴边放置，尽量不遮挡地球。
- 地球上的英文字符效果保持参考页面风格，UI 文案全部使用中文。
