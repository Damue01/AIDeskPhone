## 当前结论

- ESP32-C3 负责摘挂机/按压识别和 BLE HID 快捷键，不负责音频。
- CSR8645 负责蓝牙音频输入/输出。供电必须按模块 `BAT+ / BAT-` 标称处理，不要默认用 ESP32-C3 的 3.3V。
- RJ9/R9/4P4C 听筒线是四芯线，通常是一对喇叭线、一对麦克风线。最终线序以万用表、转接板标注和录音检查为准。
- 当前方案不接电话外线，避免振铃高压和未知线路状态。

制作步骤、接线注意和问题排查以 [../BUILD_MANUAL.md](../BUILD_MANUAL.md) 为准。
