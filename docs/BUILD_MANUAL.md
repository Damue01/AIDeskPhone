# AI Desk Phone 制作与维护手册

- 固件工程：`esp32c3_gpio0_21_test`
- 默认输入/输出：GPIO0 摘挂机输入，GPIO21 蜂鸣器，GPIO20 LED
- 默认控制台地址：`http://127.0.0.1:8765`

这份手册按实际制作顺序组织，目标是让读者能从软件预览开始，逐步完成控制链路、音频链路和最终装机。仓库里的控制台、脚本、页面、Agent runtime 和固件可以直接复用；真实电话外壳、听筒音频、供电、焊接、走线和绝缘需要用户自己完成。

## 1. 系统结构

控制链路：

```text
HG113 摘挂机开关
  -> ESP32-C3 GPIO0
  -> Wi-Fi UDP 状态上报
  -> 电脑端控制台判断 HIGH / LOW
  -> 输入法动作 / Agent 语音会话 / 回拨提醒
```

音频链路：

```text
座机听筒麦克风和喇叭
  -> RJ9/R9/4P4C 四芯听筒线
  -> CSR8645 蓝牙音频模块 MIC / SPK 焊盘
  -> Windows 蓝牙耳机输入/输出
```

两条链路独立调试。ESP32-C3 不处理音频，CSR8645 不参与快捷键控制。

## 2. 材料清单

| 材料 | 作用 | 备注 |
| --- | --- | --- |
| HG113 共电电话 | 提供外壳、听筒和摘挂机结构 | 不接电话外线高压 |
| ESP32-C3 SuperMini | 读取摘挂机状态，Wi-Fi 上报 GPIO，执行蜂鸣器和 LED 命令 | GPIO0 输入，GPIO21 蜂鸣器，GPIO20 LED |
| CSR8645 蓝牙音频模块 | 连接听筒麦克风和喇叭 | 需要 3.7V 供电 |
| RJ9/R9/4P4C 听筒线或转接板 | 分出听筒的麦克风线和喇叭线 | 四芯线，最终线序以实测为准 |
| 3.7V 电源 | 给 CSR8645 供电 | 不使用 ESP32-C3 的 3.3V，不把 5V 接到 `BAT+` |
| 万用表 | 测电压、通断和线序 | 接线前后都需要 |
| 杜邦线、夹线、热缩管、绝缘胶带 | 连接、固定和绝缘 | 装机前确认没有裸露线头 |
| Windows 电脑 | 烧录固件、打开控制台、配对蓝牙设备 | 目标软件快捷键由用户自己的软件决定 |

照片资料见 [照片索引](electronics/photo-index.md)。

## 3. 安全边界

1. 电话外线不接入。本项目只使用座机外壳、听筒和低压内部结构。
2. CSR8645 使用 3.7V 供电。
3. ESP32-C3 的 3.3V 不给 CSR8645 供电。
4. 5V 不接 CSR8645 的 `BAT+`。
5. 未确认功能的听筒线只允许接到低压音频脚，不接任何电源脚。
6. 最终装机前，所有焊点、线头和模块背面都要做绝缘和应力释放。

## 4. 软件环境

只想先体验软件，不需要接 ESP32：

```powershell
.\Start_AI_Desk_Phone.bat
```

打开：

```text
http://127.0.0.1:8765/
http://127.0.0.1:8765/command-center/
http://127.0.0.1:8765/simulator
```

控制台会在没有 ESP32 时使用本地模拟发送端。你可以先用模拟页跑通摘机、挂机、回拨、Agent 文本入口和地球页面，再开始改电话。

ESP32-C3 刷入固件后，直接运行启动脚本：

```powershell
.\Start_AI_Desk_Phone.bat
```

需要指定串口时：

```powershell
.\Start_AI_Desk_Phone.bat COM5
```

启动脚本会检查 Python 虚拟环境、安装依赖，并打开后台控制台和地球指挥中心。

真实设备联机时推荐使用：

```powershell
.\Connect_Real_Device.bat
```

它会启动一个关闭模拟模式的控制台，等待 ESP32-C3 的 UDP 遥测，并把排查日志写到 `logs/`。

首次烧录固件时，先安装 Python 依赖：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

编译固件：

```powershell
.\.venv\Scripts\platformio.exe run -d firmware\esp32c3_gpio0_21_test
```

烧录固件：

```powershell
.\.venv\Scripts\platformio.exe run -d firmware\esp32c3_gpio0_21_test -t upload
```

PlatformIO 会自动选择可用串口。电脑上有多个串口，或需要指定实际端口时：

```powershell
.\.venv\Scripts\platformio.exe run -d firmware\esp32c3_gpio0_21_test -t upload --upload-port COM5
```

如果控制台一直显示正在扫描，并且 Windows 只看到 `COM1`，说明 ESP32-C3 还没有枚举成 USB 串口。`COM1` 通常是 Windows 系统内置通信端口，不是本项目的板子。此时先换 USB 口或 USB 数据线，重新插拔几次，并检查板子供电和 BOOT/复位状态。Windows 正常识别后，控制台会自动连接新的 `COMx`。

## 5. 控制链路制作

1. 保持电话外线断开。
2. 将 ESP32-C3 通过 USB-C 连接 Windows 电脑。
3. 烧录 `firmware/esp32c3_gpio0_21_test` 固件。
4. 将摘挂机开关接入 ESP32-C3 的 GPIO0 和 GND。
5. 启动本地控制台：

```powershell
.\Start_AI_Desk_Phone.bat
```

6. 打开 `http://127.0.0.1:8765`。
7. 操作电话摘挂机机构，观察 GPIO 数字波形和解释状态变化。
8. 如果 HIGH / LOW 与实际动作相反，在页面切换“方案 1 / 方案 2”。
9. 保存配置，确认日志中出现 `ESP32 已确认配置写入板子。`

保存配置时只打开一个控制台网页窗口。打开多个 `http://127.0.0.1:8765` 页面可能占用浏览器连接，导致保存请求超时。出现超时后，关闭其他控制台窗口，只留下一个页面并强制刷新后再保存。

本项目不提供额外的串口、状态或扫描脚本。控制台就是唯一调试入口。

## 6. 输入法 / 快捷键配置原则

这一节只适用于输入法模式。快捷键由用户自己的 Windows 软件决定。制作时先确认目标软件的快捷键，再填入控制台。

示例场景：

- 语音输入软件：按下电话动作触发开始/停止语音输入。
- 通话软件：摘机接听，挂机挂断。
- 会议软件：按压静音或取消静音。

配置原则：

1. 在目标软件中确认快捷键。
2. 在控制台中分别配置按下动作和释放动作。
3. 使用“模拟按下/模拟释放”确认 Windows 能收到快捷键。
4. 再用真实电话动作验证。
5. 如果目标软件更换，重新配置快捷键即可，不需要改固件。

如果使用 Agent 模式，电话摘机后会直接进入本地语音会话，不需要给第三方软件配置开始/结束输入快捷键。

## 7. Windows 蓝牙音频配对

1. 打开 Windows 蓝牙设置。
2. 搜索并配对蓝牙耳机音频模块。
3. 在 Windows 中确认它能作为麦克风和扬声器使用。
4. 控制链路仍由 ESP32-C3 和本地控制台负责，不走蓝牙 HID。

## 8. 音频链路制作

CSR8645 负责蓝牙音频，不参与 ESP32-C3 的快捷键控制。

供电：

```text
CSR8645 BAT+ / BAT- = 3.7V
```

接线：

1. 给 CSR8645 接 3.7V 电源。
2. 长按中间按键约 4-5 秒，使模块进入红蓝闪烁配对状态。
3. 在 Windows 中把 CSR8645 配对为蓝牙耳机/免提设备。
4. 将 RJ9/R9/4P4C 听筒四芯线分成两对。
5. 喇叭候选线接 CSR8645 `L+ / L-` 或 `R+ / R-`。
6. 麦克风候选线接 CSR8645 `MIC+ / MIC-`。
7. 录音和播放都正常后，再固定焊接。

线序不能只凭颜色判断。常见颜色可以作为尝试顺序，但最终以转接板标注、万用表通断和录音/播放检查为准。

## 9. 装机检查

装回座机外壳前确认：

1. ESP32-C3 固定牢靠，USB 口可访问。
2. CSR8645 和 3.7V 电源固定牢靠。
3. 电话外线未接入。
4. 所有电源线、音频线和信号线无短路。
5. 所有裸露焊点已绝缘。
6. 听筒线活动时不会拉扯焊点。
7. 摘挂机/按压机构动作不会压到模块或线束。
8. Windows 能连接蓝牙音频模块。
9. 控制台能看到摘挂机状态，并能驱动蜂鸣器和 LED。
10. CSR8645 音频输入和输出正常。
11. 座机本体显示正常；如果显示异常或不亮，先更换座机电池。
